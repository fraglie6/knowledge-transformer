# 第一性原理拆解

## 何时使用

当问题复杂、信息矛盾，或现成答案不可靠时。

## 怎么做

1. 把问题写成一个明确的判断或目标。
2. 找出哪些是不可动摇的基本事实。
3. 去掉类比和习惯做法，只从基本事实重新推理。
4. 得到结论后，用反例和边界条件检验。

## 为什么

类比会把旧方案的错误带进新问题；第一性原理回到约束本身，减少无依据假设。

## 例子

不因为“别人都这样做”就沿用某个流程，而先问：它必须解决的约束是什么？
