# Maker-Checker 双角色

## 何时使用

当需要交付结果，且不能只靠执行者自己说“做完了”时。

## 怎么做

1. 让一个角色负责生成结果。
2. 让另一个独立角色按标准检查结果。
3. 检查角色只根据证据判断，不接受“我觉得可以”。
4. 未通过就回到生成角色修复，再重新检查。

## 为什么

生成和检查混在同一视角时，容易把“完成了动作”误当成“达成了标准”。

## 例子

写材料时，一个 agent 负责起草，另一个 agent 按清单检查是否有遗漏、虚构和格式错误。
